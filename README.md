# Gulf Watch — อ่าวไทยและอันดามัน

เว็บ production: https://gulf-watch-rouge.vercel.app/

แดชบอร์ดสาธารณะภาษาไทย สำหรับเฝ้าระวังความขุ่นและแพลงก์ตอนบลูมเบื้องต้น พร้อมแผนที่สี สรุปพิกเซลระดับสูง แนวโน้ม 6 วัน ข้อมูลสถานีน้ำท่า CSV และ iframe ใช้ Next.js บน Vercel

## ข้อมูลและขอบเขต

- Copernicus Marine `OCEANCOLOUR_GLO_BGC_L3_NRT_009_101`: SPM และ chlorophyll-a ประมาณ 4 กม. มองย้อนหลังไม่เกิน 5 วัน แสดงวันสังเกตจริงทุกจุด
- Open-Meteo Marine: คลื่นและอุณหภูมิผิวน้ำ; Open-Meteo / NOAA GFS: ลม ฝน แสง บริการมีความละเอียดหยาบกว่าดาวเทียม
- Thaiwater/RID: สถานี K.55A, C.35 และ Kgt.3 เป็นอัตราการไหลเหนือน้ำ ณ เวลารายงาน **ยังไม่ใช่ยอดน้ำจืดสุทธิออกปากแม่น้ำ ไม่รวมสถานีเข้าด้วยกัน ไม่ใช้ Q คูณสีความเสี่ยง**
- Natural Earth 1:10 million สำหรับชายฝั่ง (ไม่ใช่ความละเอียด 10 เมตร)

สีเป็นการคัดกรอง **สัมพัทธ์ ความเชื่อมั่นต่ำ ยังไม่สอบเทียบ** แบ่งข้อมูลดาวเทียมเป็น quintile แล้วปรับ 1 ระดับตามสภาพแวดล้อม ไม่ใช่ NTU/FNU โอกาสเกิดเหตุเป็นเปอร์เซ็นต์ หรือการยืนยันชนิดแพลงก์ตอนอันตราย เปอร์เซ็นต์บนแดชบอร์ดคือสัดส่วนพิกเซลที่มีข้อมูล ไม่ใช่สัดส่วนพื้นที่เสียหาย

คงสภาพดาวเทียมตั้งต้นระหว่างพยากรณ์ ยังไม่จำลองการพาตะกอน ความเค็ม สารอาหาร หรือการเติบโตของแพลงก์ตอน เมฆและตะกอนรบกวน chlorophyll ใกล้ฝั่งได้ ข้อมูลขาดไม่แทนด้วยศูนย์

## พื้นที่ทั้งประเทศและคลื่นลม (รุ่น 3)

ครอบคลุมอ่าวไทยและอันดามันเฉพาะ EEZ ประเทศไทยจาก Marine Regions / VLIZ (MRGID 8332, CC BY 4.0) กรอง sovereign1=Thailand และ sovereign2 IS NULL เพื่อตัดพื้นที่ร่วม ขอบเขตใช้เป็น mask ข้อมูล ไม่ใช่แผนที่ประกาศเขตแดน หน้าจอเลือกทั้งหมด / อ่าวไทย / อันดามันได้

- สุ่มทุก 3 พิกเซลของกริดดาวเทียม (~12 กม. จากต้นทาง ~4 กม.) ไม่ใช่การเฉลี่ยพื้นที่ 12 กม. ไม่อ้างว่าเป็นภาพดาวเทียมความละเอียด 12 กม.
- แสดงพิกเซลทะเลใน mask แม้ SPM/CHL ขาด เพื่อยังดูพยากรณ์คลื่นลมได้ สีเทาหมายถึงไม่มีข้อมูลสำหรับชั้นนั้น ไม่ใช่ค่าศูนย์
- คำนวณ quintile ความขุ่นและบลูมแยกอ่าวไทยกับอันดามัน สีสัมพัทธ์จึงเทียบภายในฝั่งทะเลเดียวกัน
- เลือกจุดแทนสภาพอากาศในกริด 0.375° (~40 กม.) และปฏิเสธกริดแบบจำลองที่ห่างจากพิกเซลเกิน 65 กม. ไม่อ้างว่าคลื่นลมละเอียด 12 กม.
- `wave`: ค่าสูงสุดรายวันของ significant wave height หน่วยเมตร ไม่ใช่ความสูงคลื่นลูกใหญ่ที่สุด
- `waveDirection` / `wavePeriod`: ทิศที่คลื่นมาจากและคาบคลื่น ณ ชั่วโมงที่ significant wave height สูงสุด แสดงเวลาไทย
- `wind`: ความเร็วลมสูงสุดรายวันที่ระดับ 10 เมตร หน่วยม./วินาที; `windDirection` เป็นทิศที่ลมมาจาก ณ ชั่วโมงลมสูงสุด; `gust` เป็นค่าสูงสุดรายวันของลมกระโชก
- ทิศทาง ณ จุดสูงสุดใช้ข้อมูลชั่วโมงเดียวกัน ไม่มีการเฉลี่ยองศาแบบเส้นตรง ลูกศรบนแผนที่ชี้ทิศที่เคลื่อนไป
- CSV รวมคลื่น ลม กระโชก ทิศทาง คาบคลื่น เวลา และฝั่งทะเล
- หากดาวเทียมไม่พอ จะว่างเฉพาะคะแนน SPM/CHL แต่คลื่นลมยังอัปเดตได้ การรับชุดใหม่ต้องมีคลื่นและลมอย่างน้อย 20 จุดต่อฝั่งทุกวันในช่วงพยากรณ์

แหล่งแบบจำลองผ่าน Open-Meteo Marine: ECMWF / Meteo-France / NOAA; อากาศใช้ NOAA GFS การแบ่งช่วงสีคลื่นลมเป็นการแสดงค่า ไม่ใช่เกณฑ์เตือนภัย ตรวจประกาศกรมอุตุนิยมวิทยาก่อนออกเรือ

`lib/thai-marine-boundary.json` และ `lib/coastline.json` เป็นไฟล์คงที่สำหรับงานรายวัน หากต้องเตรียมใหม่ ใช้ QGIS Python รัน `scripts/prepare-geography.py --land <ne_10m_land.shp>` กับข้อมูล Natural Earth 1:10 million (ไม่ใช่ 10 เมตร)


## แดชบอร์ดประชาชนทั่วไป — 28 ตุลาคม 2569

ปรับหน้าใหม่เป็นโทนฟ้า/เทอร์ควอยซ์ มีแผนที่ 8 ชั้น: คลื่น ลม ฝน SST เที่ยวทะเล ออกเรือ ความขุ่น และแพลงก์ตอน เลือกฝั่ง พิกเซล วัน ซูม ลากแผนที่ เปิด/ปิดชื่อพื้นที่และทิศทางได้ กราฟ 6 วันเชื่อมกับวันบนแผนที่และมีตารางตัวเลขรองรับ ใช้คีย์ลูกศรเลือกพิกเซลได้ รองรับมือถือและ reduced motion

### ฝนและ SST

- `rain`: ผลรวมฝน/หยาดน้ำฟ้า 24 ชั่วโมง (มม.) ปัดหนึ่งตำแหน่ง, ใช้เกณฑ์ฝนกรมอุตุนิยมวิทยา
- `thunder`: true เมื่อพบรหัสอากาศ WMO 95, 96, 99 ในวันนั้น; false คือไม่พบสัญญาณจากแบบจำลอง ไม่ใช่การยืนยันว่าไม่มีพายุ
- `sst`: ค่าเฉลี่ยอุณหภูมิผิวน้ำรายวัน (°C) ไม่ใช่อุณหภูมิอากาศหรืออุณหภูมิผิดปกติเทียบภูมิอากาศ
- ต้องมี 24 timestamp ไม่ซ้ำและค่าครบ; ข้อมูลขาดไม่แทนศูนย์
- Open-Meteo ระบุ precipitation, gust และ shortwave radiation เป็นค่าของชั่วโมงก่อนเวลา timestamp จึงใช้ 01:00 ถึง 00:00 วันถัดไปสำหรับช่วง 00:00–24:00 Asia/Bangkok และขอข้อมูลอากาศเพิ่มจนถึงวันถัดจากวันสุดท้าย
- จำกัดระยะห่างกริด SST/ฝนไม่เกิน 65 กม. เช่นเดียวกับคลื่น/ลม

### กฎกิจกรรม `weather-screening-v1`

ให้ระดับ 1–5 ของคลื่น ลม กระโชก และฝน แล้วเลือกค่าสูงสุด หากพบฝนฟ้าคะนองให้ระดับ 5 เกณฑ์ทั้งหมดและสูตรแสดงในหน้า “เข้าใจข้อมูล” และ `lib/activities.mjs` เป็นกฎคัดกรองของแอปที่ยังไม่สอบเทียบ ไม่ใช่ดัชนีท่องเที่ยวมาตรฐานหรือความน่าจะเป็นอุบัติเหตุ การท่องเที่ยวและออกเรือใช้ชุดปัจจัยเดียวกันแต่ข้อความต่างกัน ไม่ใช่หลักฐานอิสระสองชุด

ไม่รวมชนิดเรือ ขนาดเรือ ระยะห่างฝั่ง เส้นทาง กระแสน้ำ ทัศนวิสัย หรือการตรวจฟ้าผ่า ไม่ใช้ SST แทนอุณหภูมิอากาศ และไม่ตีความ CHL เป็นความปลอดภัยของน้ำ ข้อมูลจำเป็นขาด ข้อมูลเก่า หรือสถานะอัปเดตล้มเหลว จะไม่แสดงข้อสรุปเชิงเอื้อต่อกิจกรรม

CSV เพิ่ม rain, rain48, thunder, sst, generatedAt, activity_method และระดับคัดกรอง มุมมอง iframe ยังคงวันที่พยากรณ์ เวลาคำนวณ และสถานะผิดพลาด

### ตัวอย่างในเครื่องและ production

`npm run dev` อ่าน snapshot และ status ใน checkout เพื่อทดสอบข้อมูลที่เพิ่งสร้างด้วย `npm run update:data` พร้อมป้าย “ตัวอย่างจากชุดข้อมูลในเครื่อง” ส่วน production ยังอ่าน feed GitHub ตามเดิม ถ้าชุด bundled ใหม่กว่า feed ให้ใช้ bundled โดยคงสถานะ publication จริงไว้ หากอ่าน feed ไม่ได้จะเก็บ fallback และแสดงคำเตือน

เผยแพร่โค้ดผ่าน branch `main` และ Vercel Git integration ในรอบตรวจภายในเครื่อง feed GitHub เชื่อมต่อไม่สำเร็จ แต่การดึงต้นทาง Open-Meteo/Copernicus/Thaiwater เพื่อสร้าง snapshot ในเครื่องสำเร็จ สถานะ feed บน production ต้องตรวจหลัง deploy
